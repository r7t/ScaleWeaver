# 甲调 n-gram：色彩展开与收束

当前日常 `tiangan_72_5_norm` 配置使用基于老版的 `tiangan_72.ngram.balanced_76.txt`，仅降低7/6奖励；见 [老版7/6密度调整](TIANGAN_76_BALANCE.md)。下文记录的是另一份 `tiangan_72.ngram.txt` 色彩重写表，勿混淆两者。

本次只调整 `tiangan_72.ngram.txt`，保留原始格式和评分代码。原表完整备份为 `tiangan_72.ngram.pre_color.txt`，不会被当前配置自动加载。新表共有 394 条非零规则：二元 39、三元 60、四元 177、五元 118；旧表为 1179 条。

## 音级与设计意图

| 色彩 | 音与 72-EDO 音级 | 旋律处理 |
| --- | --- | --- |
| 本色 | 甲 0、庚 42 | 提供出发点、连接点和落脚点，避免只奖励回甲 |
| 火色 | 丙 16、丁 23 | 鼓励甲丙丁庚等展开，也保留丁丙甲等回收 |
| 水色 | 壬 58、癸 65 | 鼓励短回摆、换邻音和壬辛庚等落脚，允许水色持续数音 |
| 异色 | 己 35 | 支持戊己戊、庚己庚、丙己壬等局部点缀和连接 |
| 拿坡里色彩 | 乙 7、戊 30、辛 49 | 允许内部展开，再偏向戊丁、乙甲、辛庚等出口 |

这些色彩沿用项目讨论中的审美定义。拿坡里部分借用“下属扩张—属方向—稳定”的组织思路，例如乙戊辛丁庚、辛乙戊丁甲。单声部出现这串音并不等于实际演奏了 N→D→T 和弦；因此只给软奖励，不根据几个音硬判反功能，也不惩罚所有逆向连接。

## 修正旧表的两种偏向

旧表部分二音奖励达到 1.0，容易让固定音对的重要性超过完整轮廓。新表降低二音奖励，把更多偏好放到三至五音的具体展开中。不是把所有喜欢的片段都提高总分：例如戊己戊辛癸的逐音累计奖励由 2.20 降为 0.98，减少旧表对尾部音对的过强奖励。

旧表还包含 900 条 A-B-A-C-A（B≠C）的统一负分。新表取消这类一概惩罚，允许换邻音的回摆自然发生；未列出的模式为零分，并非全部改成奖励。辛壬辛癸壬、戊己戊辛癸等有明确色彩组织的模式另加小幅奖励。

持续原样重复仍受限制：所有 A-B-A-B 为 −0.38，A-B-A-B-A 为 −0.62，两项在第五音相加。A=B 也包含在内。乙戊辛三个音的双向循环另在第五音轻罚 −0.28，允许先展开，减少无限停留。

## 7/6 的方向与密度（修订）

72-EDO 的 16 步近似 7/6。恢复四组共八个方向的基础奖励：

| 音对 | 正向 | 反向 | 方向侧重 |
| --- | ---: | ---: | --- |
| 甲→丙 / 丙→甲 | 0.32 | 0.24 | 火色展开较强，回甲保留但稍弱 |
| 乙→丁 / 丁→乙 | 0.30 | 0.20 | 向属方向连接较强，返回扩张区域较弱 |
| 庚→壬 / 壬→庚 | 0.26 | 0.34 | 允许进入水色，更支持回落庚骨架 |
| 辛→癸 / 癸→辛 | 0.28 | 0.20 | 进入水色较强，返回扩张区域较弱 |

这里的方向是音级连接方向。表无法辨识实际声部上下行：例如甲→丙也可能由高甲跳向低丙；也不能凭乙→丁判定实际和弦已经进入属功能。

为减少音程口癖，新增八条三音折返抵消规则：A→B→A 中两次都是 7/6 时，三元负分精确抵消最后 B→A 的二元奖励，最后一音净偏置为零。四、五音原样重复惩罚继续叠加。旧表同样用过这种二元奖励与三元负分配套的办法，本次保留这个合理思路。

另对 56 种“四音中首尾两个连接均为 7/6、中间连接不是 7/6”的模式追加 −0.18，减少换音对反复使用的收益。辛癸壬庚同时具有值得保留的水色轮廓，因此其原四元 +0.20 与密度 −0.18 合并为一条 +0.02，避免重复键。庚壬辛癸的末音叠加为 +0.28，明显低于不考虑密度时的 +0.46。

这些约束针对局部密度，不是整曲占比上限；不能保证 7/6 的比例低于三分之一。实际占比还受其他目标与随机种子影响，需要生成后统计和试听。

## 多重匹配的预算

每次候选音的实际偏置是全部匹配后缀的和：

`B = b2(末二音) + b3(末三音) + b4(末四音) + b5(末五音)`

每阶的最大正贡献分别为 0.34、0.18、0.20、0.22，理论总奖励上限为 0.94；现有条目实际叠加上限为 0.76。这些是增量贡献，不是该模式的目标总分。代码再将偏置取负作为代价，并按使用位置施加既有权重。

以辛壬辛癸壬的最后一个壬为例：

| 匹配后缀 | 增量奖励 |
| --- | ---: |
| 癸壬 | 0.12 |
| 辛癸壬 | 0.18 |
| 壬辛癸壬 | 0.20 |
| 辛壬辛癸壬 | 0.22 |
| 合计 | **0.72** |

甲丙甲丙甲的最后一个甲则累计为 −1.00。对所有 100 种 A/B 组合检查后，第 4 音和第 5 音的净偏置均为负；短回摆的奖励不会抵消持续循环的惩罚。

穷举本音阶全部长度 2～5 的序列，共 111100 个上下文，实测逐次偏置范围：

| 上下文长度 | 最小值 | 最大值 |
| --- | ---: | ---: |
| 2 | 0.00 | 0.34 |
| 3 | 0.00 | 0.52 |
| 4 | −0.38 | 0.72 |
| 5 | −1.00 | 0.76 |

以上范围针对原始 n-gram 偏置，不是整首曲子的总分，也不是含所有声部权重的优化目标范围。

## 生效范围与局限

12 个引用此表的甲调配置均已通过实际加载检查；`python3 -m unittest discover -v` 的 51 项现有测试全部通过。表内音级合法、权重有限且无重复键。癸调使用独立表。当前代码还将 `lead` 表应用于伴奏声部，所以本表会影响伴奏走向；本次没有增加额外的 `bass` 规则。

表只识别音级序列，不知道八度、时值、强弱拍、和弦或乐句位置。甲丙丁庚的奖励不能保证实际音高向上；A-B 循环惩罚也不能区分八度变化。表不能实现第 39 小节减密、第 40 小节提前四分之一拍到达，也不能保证每句的色彩比例。本次保留现有音级分布、和声和节奏设置。

这是一版可回退的审美先验，不代表已验证听感提升。下一轮应使用相同配置与多组固定种子对照原表和新表，关注：水色是否形成有落脚的回摆、火色是否能展开、己是否保留点睛作用、拿坡里区域是否有出口，以及伴奏是否被旋律先验过度牵引。不要把更高的表内奖励直接当成更好听的证据。
